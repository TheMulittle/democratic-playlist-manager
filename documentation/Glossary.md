# Glossary

- Unauthenticated user: an user that is not yet authenticated to the system
- Host (user): an authenticated user that uses the system to manage their playlists on their behalf. The user is said to be a host of a playlist. A host can become invitee in other host's playlists
- Invitee (user): an authenticated user that uses the system to interact with a managed playlist. The user is said to be an invitee of a playlist
- Managed playlist: a playlist that is being managed by the system on behalf of a host user. "Managing" a playlist is heavily overloaded term as it will have multiple meanings depending on the context. A host manages a playlist in the sense that they select what playlists will be managed by the system and what criteria will be used for managing it. An invitee manages a playslist in the sense they operate on it, i. e., they (ask the system to) add/remove/reorder their own songs in a playlist. The system manages a playlist as it operates on it, i. e., create/add/remove/reorder the songs in the playlist
